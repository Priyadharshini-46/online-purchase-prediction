PROJECT OVERVIEW

Understanding the Dataset

The system uses the Online Shoppers Purchasing Intention Dataset to analyze customer browsing behavior and predict whether a shopping session results in a purchase.

01

Problem

Predict whether an online shopping session will result in a purchase based on customer browsing and session behavior.

02

Dataset

The dataset contains 12,330 online shopping sessions with 17 input features and the Revenue target variable.

03

Target Variable

Revenue represents the purchase outcome. False indicates no purchase, while True indicates a purchase.

04

Classification Model

K-Nearest Neighbors (KNN) is used to classify sessions based on the behavior of their nearest neighboring sessions.

Dataset Size 12,330 Sessions
Input Features 17 Features
Target Revenue
Classes Purchase / No Purchase

INFERENCE

What Do These Results Tell Us?

The KNN classifier achieved an accuracy of 86.74% on the test dataset. The precision of 61.70% indicates that around 62% of sessions predicted as purchases were actual purchases.

The recall of 37.96% shows that the model identified around 38% of the actual purchase sessions. The F1-score of 47.00% reflects the balance between precision and recall.

The confusion matrix shows 1,994 correctly classified no-purchase sessions and 145 correctly classified purchase sessions. However, 237 actual purchase sessions were missed. Therefore, while the model achieves good overall accuracy, identifying actual purchasers remains a challenge.
